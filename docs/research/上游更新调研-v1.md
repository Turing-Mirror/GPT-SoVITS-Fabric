V5 要点：

- 底模目录 `GPT_SoVITS/pretrained_models/gsv-v5-pretrained/`，文件 `s2Gv5dev.pth`、`s2Gv5turbo.pth`；GPT 侧沿用 `s1v3.ckpt`。
- 走 v4 那条 vocoder 路线（`v3v4set` 扩成含 v5）；`v5turbo` 默认 4 步采样，`v5dev` 默认 32 步、cfg 1.30。
- 训练走 LoRA（`process_ckpt.py` 新增版本头 `07:v5dev-lora`、`08:v5turbo-lora`），与 v3/v4 同路径；webui 训练版本下拉改为 v2 / v2Pro / v2ProPlus / v4 / v5dev / v5turbo，**v1 已从训练选项中移除**。
- 推理识别版本仍靠 `get_sovits_version_from_path_fast` 读检查点头与哈希，不依赖外部告知。

## 三、对本仓的影响

1. 合成：`synth_worker.py` 用到的 `TTS_Config` / `TTS` / `init_vits_weights` / `init_t2s_weights` / `run()` 键名都还在。`streaming_mode` 传布尔值不触发新的 `validate_streaming_options`（只有 `gpt_streaming=True` 才校验）。
2. 合成：`synth_worker.py` 第 202 行的版本白名单不含 `v5dev` / `v5turbo`，升级后 V5 角色会以 v2 的语种表起步，需要补进白名单。
3. 训练：`s2_train.py` 内部改为单卡直跑，命令行与配置键未变；`train_worker.py` 不需改。若要开 V5 训练，需要接 `s2_train_v3_lora.py` 这条路，属于新功能（D5 已写明 v3/v4 未开）。
4. 打包：`cnhubert.py`、`uvr5/mdxnet.py` 新增 `import tools.portable_runtime`。`prepare_engine_payload.py` 整个搬 `tools/`，这个文件会随包带上，无需改脚本。
5. 依赖：原 `requirements.txt` 未改；新增的 Py3.12 清单与本仓 D3（Python 3.10）不同。Accel 加速是否在 3.10 运行时可用，需要实测。
6. 发布前另需处理：`app/src-tauri/engine-payload/README.md` 仍是 RVC Fabric 的说明（e623c86 带入）。
