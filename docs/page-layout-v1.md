# 页面布局 v1

日期：2026-11-07。

## 模型与标注

模型页和标注文件列表共用 `ModelCard` 与 `useModelGrid`。列数复用 RVCF 的 `colsForWidth`：最多五列，窄窗口减少列数，每页三行。封面、名称和操作沿用模型页原有样式；模型菜单、封面编辑及跳转行为保留。

标注页以角色封面卡片显示标注文件，点击卡片打开对应文件，元信息保留文件名和行数。删除“尚未打开标注文件”整个区块及重复打开按钮。未打开文件时，页头“打开 .list”为主按钮；进入编辑器后继续突出保存操作。标注加载、编辑、保存和未保存改动确认保持原流程。

## 设置与说明

设置页使用与“其他”页相同的阅读宽度及 `Group`、`ListItem` 分组行：说明在左，控件在右。外观、常规与在线更新页签继续保留，切换接入 TRM UI `Panes`。所有设置项、提示与处理函数保留。

说明页原已使用相同的分组问答组件，本次统一阅读宽度并收紧小节间距；搜索、展开、术语和定位链接保留。本轮样式应用范围为设置和说明，其他页面不扩展此布局。

## 验证

- 前端 62 项测试通过；构建、类型、lint、八语言文案检查通过。
- Chromium 检查 1920、1180、880 像素宽度。模型与标注在前两种宽度采用五列，880 像素宽度采用三列。
- 八语言 880×640 无横向溢出，包含已设置背景图及自定义横幅的控件状态。
- 使用真实角色元数据、模拟原生接口验证卡片打开标注、编辑与保存、设置保存、检查更新及说明搜索与深链接。
- 完整开发实例另行加载本轮前端；浏览器检查未写入真实标注或设置。

临时预览、截图及测试数据保存在被忽略的 `data/ui-qa/`，不提交用户模型和构建产物。
