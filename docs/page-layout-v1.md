# 页面布局 v1

日期：2026-11-07。

## 模型与标注

模型页和标注文件列表共用 `ModelCard` 与 `useModelGrid`。列数复用 RVCF 的 `colsForWidth`：最多五列，窄窗口减少列数，每页三行。封面、名称和操作沿用模型页原有样式；模型菜单、封面编辑及跳转行为保留。

标注页以角色封面卡片显示标注文件，点击卡片打开对应文件，元信息保留文件名和行数。删除“尚未打开标注文件”整个区块及重复打开按钮。未打开文件时，页头“打开 .list”为主按钮；进入编辑器后继续突出保存操作。标注加载、编辑、保存和未保存改动确认保持原流程。

## 设置与说明

设置页恢复原有全宽布局与 Field 控件排列，不再使用居中阅读宽度。页签外层保持不裁切阴影，类别切换采用普通左右平移。

说明页与其他页保留居中阅读宽度和紧凑分组。相同布局同步到 RVC Fabric 的这两个页面，RVC Fabric 设置页继续使用原有宽布局。

## 分类与分页

标注编辑列表每页 10 条；打开与返回标注文件、全部/问题筛选和翻页均采用普通左右切换。跨页保留编辑，保存提交整份文件的行数据。角色文件列表仍与模型页采用相同五列上限与三行分页。

模型翻页、合成单条/批量类别与参考音频分页、训练步骤以及存储分页复用现有 CatalogTransition（TRM UI QueueList）。切换使用全宽水平平移，不淡出、不缩放；普通输入和任务进度更新不重新播放切换。

共享实现固定引用 TRM UI `8936ca2e5369f8ab90251203e8cdf03d23c0d0e7`，组件和键盘行为由共享包维护。

## 自定义内容首帧修复（2026-11-08）

首页、设置页共享当前窗口最近读取的配置快照。切回页面时同步读取快照，后台再刷新；首次加载尚未读取配置时，不显示默认横幅冒充用户内容。清空自定义标题后仍正常显示默认标题。

本地待保存修改、成功保存和其他窗口的 config-changed 事件均更新快照。较早发出的读取或写入响应不能覆盖较新的字段；保存确认即使没有改变乐观显示值，也会推进字段版本。读取失败时保留已知内容。所有窗口从入口订阅配置事件，页面离开后仍可接收更新。

GSVF 的首页角色及最近合成记录保留上次成功结果，返回时不再闪出无角色、无记录的空状态。原有页面布局与切换动画保持不变。
