# 通用功能与本地角色 v1

## 通用功能

模型卡片支持更换图片、裁剪和恢复默认封面。编辑后的图片使用内容摘要命名，更新后不会继续显示旧缓存；原始图片保留。透明 PNG 转 JPEG 时铺设浅色实色背景，预览与保存使用同一份输出。裁剪沿用 RVC Fabric 的缩放、拖动和比例选择，基础控件与弹窗动效使用 TRM UI。

存储统计按角色库、训练文件、合成音频、运行环境、基础模型、人声分离模型、缓存和其他用户文件分类。目录联接、重复路径和嵌套输出目录只计算一次。自定义训练输出计入训练文件。

首页最近合成使用紧凑白色条目，按可用宽度换行，只显示完整放得下的条目。首页不产生纵向滚动。切页时离场页面停止接收交互；配置写入按顺序执行，离开页面前提交待保存的更改，避免状态回退。

“其他”页移除重复的“资源与高级”区域，模型下载集中在广场。训练数据页的“去除伴奏”与标注文件使用同样的面板结构。训练队列见 [训练队列 v1](training-queue-v1.md)。

## 发布资源

CNB 发布仓管理 `catalog/sources.json` 与生成的 `index.json`，另提供 `plaza.json`、`changelog.json`。大文件使用 Release 附件；Git 只存清单、文档和 SHA-256 校验文件。

`GSV-engine-core` 包含五个基础资源包与三个 V5 权重；`GSV-runtime` 包含 NVIDIA 和 CPU 运行环境。人声分离资源复用 RVC Fabric 的公共发布附件。本地角色权重与语料不在此次公共资源发布中。

发布时通过 CNB CLI 取得上传地址，完成后回读服务器 SHA-256。连接中断时先核对已有附件，只重传缺失资源。`publish_asset.py` 从 PATH 查找 CNB CLI，兼容 Windows 的 `cnb.exe`。
